# Coform Python SDK 0.1.0

Manage saved Division maps with the dashboard API and execute deployed Divisions
with the agentic core API using the same dashboard-issued bearer key.

Begin with [installation and key selection](getting-started.md). Use the
[map walkthrough](maps.md) to build a graph, [integration guide](integrations.md)
to upload tools, and [invocation guide](invocations.md) to consume execution events.
[Lifecycle operations](lifecycle.md) cover deployment, schedules, transfers,
monitoring, and share/embed configuration.

The [coverage matrix](coverage.md) connects each UI operation to SDK methods,
HTTP routes, and selected permission IDs. The [API reference](reference.md)
is generated from the shipped type annotations and docstrings. Read
[dashboard authentication](dashboard-auth.md) before rolling out the SDK and
[troubleshooting](troubleshooting.md) before recovering interrupted mutations.

No hosted URL is assumed. No package or documentation publication is performed.
The built documentation is a local static site in `site/`.
